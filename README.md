## Project Overview
This project analyses 500 sales orders (Jan - Oct 2025) across 4 regions and 4 categories to find sales trends, top products and regional performance.

## Key Insights
1. Total Sales: Rs. 2,78,87,760 from 500 orders
2. Electronics is highest revenue category
3. East Region contributes highest sales - 31.6%
4. Furniture is second highest category

## Power BI Dashboard
1. KPI Cards: Total Sales, Total Orders, Avg Order Value
2. Bar Chart: Sales by Category
3. Pie Chart: Sales by Region
4. Line Chart: Monthly Sales Trend
5. Slicers: Region, Category, Date
